# Octave Executive Briefing Site

Static multi-page website for an executive discussion with Octave leadership on Agentforce for Sales.

## Pages

- `index.html` - Executive Summary
- `external-research.html` - External Research
- `vignette-1.html` through `vignette-5.html` - Five vignettes
- `capability-map.html` - Capability map and sequencing
- `salesforce-summary.html` - Salesforce capability summary by domain

## Local Preview

Open `index.html` in a browser, or run any static file server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Replit Publishing

1. Import this GitHub repository in Replit.
2. Choose a static deployment.
3. Enable password protection in Replit deployment settings.
